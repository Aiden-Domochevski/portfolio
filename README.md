## 🚀 Fonctionnalités & Structure de la Page

Le portfolio est contenu dans un unique fichier `index.html` hautement optimisé, prêt à être ouvert instantanément dans n'importe quel navigateur moderne sans serveur complexe ni dépendances npm locales.

### 1. 🌌 Hero Section Interactive
- **Fond de particules interactif** codé en HTML5 Canvas avec détection de proximité souris et liaisons dynamiques de constellations.

- **Badges de statut** : Candidature active pour LMS Formation, disponibilité immédiate à Casablanca.
- **Boutons d'action (CTA)** rapides vers les projets, le profil et le formulaire de contact.
- **Indicateur de défilement animé** (souris stylisée avec molette pulsante).

### 2. 👤 Section À Propos & Compétences Clés
- **Biographie professionnelle ciblée** pour l'éducation digitale, la vulgarisation scientifique et l'intelligence artificielle appliquée à la formation.
- **Grille de compétences avec barres de progression animées** déclenchées au scroll via `IntersectionObserver` :
  - **Python** (95%)
  - **AI / Machine Learning** (90%)
  - **Agent Systems** (90%)
  - **Flask / Web Development** (92%)
  - **3D Graphics & WebGL** (88%)
  - **Video Production** (85%)
- **Bannière Synergie LMS Formation** explicitant l'adéquation du profil avec les enjeux de l'e-learning et de la formation professionnelle au Maroc.

### 3. 💼 Section Projets (3 Réalisations Clés)
Chaque projet est présenté sous forme de carte en glassmorphism avec des métadonnées riches, des tags technologiques et une fenêtre modale d'architecture détaillée :

1. **🎬 AI Video Capsule Generator**
   - *Description* : Outil intelligent de création automatisée de capsules vidéo éducatives. Utilise l'IA pour générer des scripts, des animations et produire des vidéos professionnelles complètes.
   - *Technologies* : `Python`, `MoviePy`, `Pillow`, `Flask`, `AI Generation`
   - *Points forts* : Script generation, Animated transitions, Text-to-video, Web interface.
   - *Modale* : Détail du pipeline, extrait de code MoviePy d'automatisation et métriques de productivité.

2. **🎨 Interactive Multimedia Showcase**
   - *Description* : Collection d'expériences multimédias interactives incluant des présentations 3D, des visualisations de données animées, des infographies interactives et des simulations de particules.
   - *Technologies* : `Three.js`, `WebGL`, `D3.js`, `Canvas`, `CSS3 3D`
   - *Points forts* : 3D Presentations, Data Visualization, Particle Physics, Animated Infographics.
   - *Modale* : Analyse de l'impact neuro-éducatif des technologies 3D WebGL et shaders.

3. **🤖 Multi-Agent AI System**
   - *Description* : Framework multi-agent intelligent pour l'automatisation de tâches, la modélisation de systèmes et l'optimisation de processus. Architecture modulaire avec communication inter-agents.
   - *Technologies* : `Python`, `Flask`, `Pandas`, `NetworkX`, `Scikit-learn`
   - *Points forts* : Task Automation, Process Optimization, Data Analysis, Real-time Dashboard.
   - *Modale* : Rôles des agents (Orchestrateur, Analyste, Qualité) et journal télémétrique d'exécution.

- **Palette de couleurs Dark Theme** : Nuances profondes (`#070b14`, `#0f172a`), contrastées par des dégradés néon indigo, pourpre et cyan (`#6366f1`, `#a855f7`, `#06b6d4`).

- **Animations discrètes & professionnelles** : Transitions douces au survol, lueurs ambiantes flottantes, barres de progression fluides.
- **Typographie premium** : Combinaison de `Plus Jakarta Sans` pour les titres et paragraphes, et de `Fira Code` pour les extraits techniques.
- **Entièrement Responsive** : Adaptation fluide sur mobile (<768px), tablette (768px-1024px) et écran large (>1024px).

## 💻 Instructions de Lancement

Le site ne nécessite aucun bundler (comme Webpack ou Vite). Il s'exécute directement :

1. Naviguez dans le dossier :
   ```powershell
   cd "C:\Users\salah\.gemini\antigravity\scratch\portfolio-ia-lms\portfolio-website"
   ```

2. Double-cliquez sur `index.html` ou ouvrez-le avec votre navigateur préféré :
   ```powershell
   Start-Process "index.html"
   ```

3. (Optionnel) Pour tester via un serveur HTTP local léger :
   ```powershell
   python -m http.server 8080
   # Ouvrez ensuite http://localhost:8080 dans votre navigateur
   ```
